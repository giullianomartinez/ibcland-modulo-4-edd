# IBCLand-Modulo-4-EDD

Proyecto desarrollado para la asignatura **INF2223 - Estructuras de Datos**.

Este sistema modela la operación básica de **IBCLandia**, un parque de diversiones, permitiendo gestionar zonas temáticas, atracciones, visitantes, entradas y filas de espera mediante estructuras de datos implementadas en ANSI C.

## Características

- Gestión de zonas temáticas.
- Gestión de atracciones.
- Administración de visitantes y entradas.
- Control de filas de espera.
- Búsqueda y ordenamiento de datos.
- Consultas y reportes de operación del parque.

## Tecnologías
